### 1. 方案结论与研究定位

#### 1.1 研究主题
在外生移动、动态邻居、显式 UAV 资源异构、业务负载异构、建筑物遮挡、有限无线资源、不完美 CSI、传输/计算队列和任务截止期共同存在的条件下，研究动态异构多 UAV 的单跳 U2U-MEC 协同卸载与资源调度问题。

本文区分两类异构性：
- **资源异构：** 最大 CPU、最大发射功率、初始能量和 CPU 动态能耗系数不同；
- **负载异构：** 不同 UAV 的任务到达强度不同。

资源异构描述 UAV 本身的硬件和能源差异；负载异构描述 UAV 所承受的外部业务压力。两者不得混为同一概念。

#### 1.2 最终研究问题
在不进行 UAV 轨迹优化、不允许多跳、不允许任务多目的地拆分的条件下，建筑物遮挡、频谱复用干扰、CSI 陈旧、UAV 资源异构和业务负载异构如何共同影响 U2U-MEC 任务的端到端截止期完成率？

约束感知图多智能体策略能否在动态候选邻居、现实局部观测和离散硬资源约束下，优于本地执行、启发式调度和分支式 GAT-QMIX 基线？

#### 1.3 研究主线
1. 外生移动与动态邻居；
2. UAV 资源异构与业务负载异构；
3. 几何可见性与建筑物遮挡；
4. 空间相关阴影、槽级衰落和不完美 CSI；
5. 固定资源组上的同频干扰与有效速率；
6. 已绑定任务的跨时隙传输服务；
7. 本地与远程 CPU 队列服务；
8. 任务端到端时延与截止期；
9. 约束感知图多智能体协同卸载。

#### 1.4 主实验、保底实验与扩展实验
| 层级         | 内容                                                         | 是否进入主论文 |
| :----------- | :----------------------------------------------------------- | :------------- |
| **主实验**   | 显式资源/负载异构、建筑物几何遮挡、空间相关阴影、固定资源组、跨时隙传输/计算队列、不完美 CSI、EDF 调度、CA-GAT-MAPPO | 是             |
| **保底实验** | 与主实验共享环境、观测、动作分支、mask、硬约束和奖励，使用分支式 GAT-QMIX | 是             |
| **扩展实验** | 第三 UAV Fresnel 软遮挡、连续资源动作、Sionna RT 离线回放、UAV 数量 OOD、类型 embedding | 视时间进入附录 |
| **明确不做** | 轨迹优化、RIS、多跳、DAG、完整 MIMO、实时射线追踪、完整 HARQ、ns-3 包级联动 | 否             |

#### 1.5 创新表述边界
不把 GATv2、GRU、MAPPO 或 QMIX 本身声称为全新算法。可辩护贡献为：
面向动态候选邻居、异构资源能力、截止期任务队列和联合硬约束的图多智能体决策接口，以及“资源异构—遮挡—负载不均衡—协同收益”的系统实验分析。

### 2. 研究假设与待验证假设

- **H1：跨时隙队列假设**
  相较于静态 $D/R$ 时延估计，任务级传输队列和计算队列能够更真实地反映遮挡恢复、排队等待、服务中断和截止期违约。
- **H2：协同收益假设**
  U2U 协同收益主要出现在源 UAV 负载较高、邻居计算余量较大且链路可用性较好的场景；在高遮挡、高干扰或邻居过少时，协同收益下降。
- **H3：时序观测假设**
  在 CSI 陈旧、消息延迟和短期 outage 存在时，GATv2+GRU 应比无图或无历史的局部策略更稳定。
- **H4：约束接口假设**
  动作 mask、离散降档、联合半双工冲突解析和 hard-feasible 执行器能够消除非法动作，同时保持任务、bit、cycle 和能量守恒。
- **H5：资源异构协同假设**
  当 UAV 的 CPU、功率、初始能量和 CPU 能效存在差异时，策略应更倾向于把紧迫任务迁移到具有可用计算余量、可接受能耗和可靠链路的邻居。
- **H6：负载异构协同假设**
  当不同 UAV 的任务到达强度存在差异且全局平均负载保持不变时，协同卸载应形成可观测的负载迁移行为；异构程度过高时可能出现新的接收端瓶颈。
- **H7：资源组抽象假设**
  固定资源组能够保留同频复用干扰和带宽竞争的主要决策效应，同时显著降低任意 RB 起点带来的动作空间膨胀。
- **H8：高保真趋势验证假设**
  轻量信道训练策略在离线高保真传播轨迹上的性能排序和退化趋势具有一定一致性，但不主张轻量模型完全等价于真实 U2U 信道。

### 3. 系统对象、默认参数与异构生成

#### 3.1 UAV 网络
UAV 集合为：
$$\mathcal U=\{1,2,\ldots,N\}$$
离散时隙为：
$$t=0,1,\ldots,T-1$$
每个时隙长度为 $\Delta t$。

主训练规模为 $N\in\{4,6,8\}$。只有在集合式 critic、padding 和 mask 均通过验证后，才进行 $N=10,12$ 的可选 OOD 测试。

#### 3.2 主实验基础参数
| 参数               | 初始默认值                                | 敏感性或校准范围                   | 说明                       |
| :----------------- | :---------------------------------------- | :--------------------------------- | :------------------------- |
| 区域               | $1000\times1000$ m                        | $500\times500$、$1500\times1500$ m | 固定高度二维移动           |
| 高度               | 80 m                                      | 60–120 m                           | 主实验固定高度             |
| 速度               | 10 m/s                                    | 5–20 m/s                           | 外生移动                   |
| 载频               | 3.5 GHz                                   | 2.0、3.5 GHz                       | sub-6 GHz                  |
| 总带宽             | 20 MHz                                    | 10、20 MHz                         | 系统共享                   |
| 等效 RB 数量       | $R=20$                                    | 10、20、40                         | 不等同于标准 PRB           |
| 固定资源组数       | $G=5$                                     | 固定                               | 保证 $R/G$ 为整数          |
| 每组 RB 数         | $R/G$                                     | 2、4、8                            | 分别对应 $R=10,20,40$      |
| 最大通信功率参考值 | $P_{\mathrm{ref}}=1$ W                    | 0.5–2 W                            | profile 基准               |
| 最大 CPU 参考值    | $f_{\mathrm{ref}}=2.0\times10^9$ cycle/s  | 1–4 GHz 等效频率                   | profile 基准               |
| CPU 能耗系数参考值 | $\kappa_{\mathrm{ref}}=1.0\times10^{-28}$ | pilot 后校准                       | 需与 $f^3$ 模型配套        |

| 天线增益           | 2 dBi                                     | 固定或敏感性分析                   | 发送/接收相同              |
| 噪声系数           | 7 dB                                      | 5–9 dB                             | 转为线性值参与 SINR        |
| 时隙长度           | $\Delta t=20$ ms                          | 10、20、50 ms                      | 主时间尺度                 |
| episode 长度       | $T=500$                                   | 300–1000                           | 默认 10 s                  |
| 最小安全距离       | 10 m                                      | 5–20 m                             | mobility 模块保证          |
| 候选通信半径       | 500 m                                     | 链路预算校准                       | 新任务候选邻居             |

以上数值属于编码初始基线。正式主实验前必须通过参数校准阶段确认任务既非全部完成，也非全部过期，且能量变量在 episode 内具有可观测作用。

#### 3.3 资源异构与负载异构分离
UAV $i$ 的资源特征定义为：
$$\boldsymbol{\chi}_i^{res} = \left[ f_i^{\max}, P_i^{\max}, E_i^0, \kappa_i \right]$$
业务负载参数定义为：
$$\boldsymbol{\chi}_i^{traffic} = [\lambda_i]$$
其中：
- $f_i^{\max}$：最大 CPU 频率，单位 cycle/s；
- $P_i^{\max}$：最大发射功率，单位 W；
- $E_i^0$：episode 初始主动通信/计算能量，单位 J；
- $\kappa_i$：CPU 动态能耗系数；
- $\lambda_i$：任务到达概率或强度，只属于业务过程。

真实 $\lambda_i$ 只用于环境生成。执行期 actor 不直接读取真实 $\lambda_i$，而读取历史估计：
$$\hat{\lambda}_i(t) = \frac{1}{W_\lambda} \sum_{\tau=t-W_\lambda+1}^{t}A_i(\tau)$$

#### 3.4 可解释硬件 profile
主实验不再对各资源参数进行完全独立的大范围采样，而采用 profile 加小扰动：

| Profile                | $f_i^{\max}/f_{\mathrm{ref}}$ | $P_i^{\max}/P_{\mathrm{ref}}$ | $E_i^0/E_{\mathrm{ref}}^0$ | $\kappa_i/\kappa_{\mathrm{ref}}$ | 解释                   |
| :--------------------- | :---------------------------- | :---------------------------- | :------------------------- | :------------------------------- | :--------------------- |
| **Resource-poor**      | 0.7                           | 0.8                           | 0.8                        | 1.20                             | 计算、通信和能效均较弱 |
| **Balanced**           | 1.0                           | 1.0                           | 1.0                        | 1.00                             | 参考型                 |
| **Compute-rich**       | 1.5                           | 1.0                           | 1.1                        | 0.90                             | CPU 强且相对节能       |
| **Energy-limited**     | 1.0                           | 0.8                           | 0.5                        | 1.10                             | 能量预算紧张           |
| **Communication-rich** | 1.0                           | 1.5                           | 1.1                        | 1.00                             | 发射能力较强           |

profile 确定主要相关结构后，对各参数施加不超过 $\pm5\%$ 的可复现小扰动。profile 分配和扰动均由独立随机种子控制，并写入日志。

#### 3.5 三档异构场景
| 场景                     | 配置方式                                             | 用途     |
| :----------------------- | :--------------------------------------------------- | :------- |
| **Homogeneous**          | 所有 UAV 使用 Balanced profile，且业务到达率相同     | 同构对照 |
| **Mild-Heterogeneous**   | 以 Balanced 为主，混入少量其他 profile；负载差异较小 | 主实验   |
| **Strong-Heterogeneous** | 多种 profile 并存，资源与负载差异明显                | 压力测试 |

资源异构等级与负载异构等级分别配置，不得由一个标签同时控制两者。

#### 3.6 能量标定协议
参考满负载能耗由 pilot episode 测得：
$$E_{\mathrm{full}} = \sum_{t=0}^{T-1} \left( E_i^{tx}(t)+E_i^{cpu}(t) \right)$$
若目标耗电比例为 $d$，则初始能量可按下式调整：
$$E_i^0 = \frac{E_{\mathrm{full}}}{d}$$
目标档位为：

| 能量档位      | 满负载 episode 目标耗电比例 |
| :------------ | :-------------------------- |
| Low-energy    | 70%–90%                     |
| Medium-energy | 40%–60%                     |
| High-energy   | 10%–30%                     |

若能量几乎不影响动作，降低 $E_i^0$；若大量任务因电量耗尽而整体失败，提高 $E_i^0$ 或降低 $\kappa_i$。不得在主实验中使用未经 pilot 标定的能量参数。

#### 3.7 外生移动
主实验采用固定高度二维 Gauss-Markov 模型：
$$\mathbf v_i(t+1) = \alpha\mathbf v_i(t) + (1-\alpha)\bar{\mathbf v}_i + \sqrt{1-\alpha^2}\boldsymbol\varepsilon_i(t)$$
$$\mathbf p_i(t+1) = \Pi_{\mathcal A} \left( \mathbf p_i(t)+\Delta t\mathbf v_i(t+1) \right)$$
默认 $\alpha=0.85$。边界采用反射或速度反向。安全距离由轨迹生成器保证，不属于 actor 动作。

#### 3.8 建筑物场景
建筑物用二维多边形与高度组成的柱体表示。

| 场景   | 建筑物密度 | 高度范围 | 用途         |
| :----- | :--------- | :------- | :----------- |
| None   | 无         | 无       | 自由空间对照 |
| Low    | 低         | 20–50 m  | 基本连通性   |
| Medium | 中         | 20–80 m  | 主实验       |
| High   | 高         | 30–100 m | 遮挡压力测试 |

测试集使用独立建筑物随机种子，避免训练与测试共享同一布局。

### 4. 任务模型、队列模型与时隙边界

#### 4.1 任务记录
每个任务保存：
$$\tau_n= \left( id_n, i_n, D_n, C_n, t_n^{arr}, t_n^{ddl}, D_n^{rem}, C_n^{rem}, d_n^{dst}, state_n \right)$$
其中：
- $D_n$：任务输入数据量，单位 bit；
- $C_n$：任务总计算量，单位 cycle；
- $D_n^{rem}$：剩余待传输 bit；
- $C_n^{rem}$：剩余待执行 cycle；
- $d_n^{dst}$：已绑定目的 UAV；
- $state_n\in\{\mathrm{unbound},\mathrm{local},\mathrm{tx},\mathrm{cpu},\mathrm{done},\mathrm{expired}\}$。

任务不可拆分到多个目的 UAV，不允许多跳转发。

#### 4.2 任务到达
每个 UAV 每个时隙最多生成一个任务：
$$A_i(t)\sim\mathrm{Bernoulli}(\lambda_i)$$
全局平均负载与 UAV 间负载不均衡分别配置。负载异构实验改变各 $\lambda_i$ 的离散程度，但保持平均到达率不变。

任务参数为：
$$D_n\sim U(0.25,1.5)\ \mathrm{Mbit}$$
$$\frac{C_n}{D_n} \sim U(300,1000)\ \mathrm{cycle/bit}$$
deadline 由参考服务时间生成：
$$t_n^{ddl} = t_n^{arr} + \left\lceil \frac{ \eta_n \left( D_n/R_{\mathrm{ref}} + C_n/f_{\mathrm{ref}} \right) }{ \Delta t } \right\rceil$$
其中 $\eta_n\sim U(1.5,3.0)$，最终 deadline 限制在 10–150 个时隙内。

#### 4.3 队列集合
环境保存：
- $Q_i^{unb}$：未绑定任务列表；
- $Q_i^{loc}$：在源 UAV 本地执行的任务列表；
- $Q_{i\rightarrow j}^{tx}$：源 UAV $i$ 发往目的 UAV $j$ 的传输任务列表；
- $Q_{i\rightarrow j}^{cpu}$：来源为 $i$、在目的 UAV $j$ 上执行的远程 CPU 任务列表。

所有队列按 EDF 排序：
$$slack_n(t)=t_n^{ddl}-t$$

#### 4.4 路由与目的地锁定
对于 $Q_i^{unb}$ 中 EDF 优先级最高的一个任务：
- 可选择 local；
- 可选择 defer；
- 可选择当前候选邻居 $j$。

首 bit 发送前允许未绑定任务重新决策；任务进入传输队列并发送首 bit 后，目的 UAV 锁定。已锁定任务不允许自动重路由。

#### 4.5 端到端时延
若任务 $n$ 在时隙 $t_n^{cmp}$ 完成，则：
$$T_n^{E2E} = (t_n^{cmp} - t_n^{arr} + 1)\Delta t$$
任务在截止时隙结束后仍未完成，则记为过期：
$$\mathrm{expired}_n = \mathbb 1 \left\{ t_n^{cmp}>t_n^{ddl} \text{ 或任务在 } t_n^{ddl} \text{ 结束时仍未完成} \right\}$$

#### 4.6 槽边界与任务可用性
每个时隙遵循以下因果规则：
1. 槽初读取已有任务、队列、估计 CSI 和延迟消息；
2. 槽内只能服务槽初已存在的传输和 CPU 队列；
3. 本槽新路由任务在槽末进入本地或传输队列；
4. 本槽传输完成任务在槽末进入目的 UAV 的 CPU 队列；
5. 槽末进入新队列的任务下一时隙才可被服务；
6. 槽末生成的新任务下一时隙槽初才进入可决策集合；
7. 不允许同一任务在一个时隙内完成路由、传输和计算。

### 5. 动态拓扑模型

#### 5.1 新任务候选邻居
$$\mathcal{N}_i(t) = \left\{ j\ne i: d_{ij}(t)\le R_{cand} \right\}$$
主实验使用 $R_{cand}=500$ m，并通过链路预算校准。可采用距离滞回：
$$R_{on}=450\ \mathrm{m}, \qquad R_{off}=550\ \mathrm{m}$$

#### 5.2 新任务边与服务边分离
- **新任务边：** 只决定未绑定任务当前可选的目的 UAV；
- **服务边：** 已绑定传输任务保留其目的 UAV，即使暂时超出新任务候选范围；
- 链路暂时不可用时，任务保留剩余 bit 并等待恢复；
- outage 不直接删除已锁定服务边。

### 6. 轻量 U2U 信道模型

#### 6.1 建模目标
主训练环境只保留能够影响卸载和资源决策的传播机制。该模型用于可训练、可解释和可验证的趋势研究，不替代完整物理层仿真器。

#### 6.2 建筑物遮挡
UAV $i$ 到 UAV $j$ 的线段为 $\ell_{ij}([0,1],t)$。建筑物集合记为 $\mathcal B$，第 $b$ 个建筑物体为 $\mathcal B_b$。
建筑物遮挡指示量为：
$$I_{ij}^{bld}(t) = \mathbb 1 \left\{ \exists b\in\mathcal B: \ell_{ij}([0,1],t) \cap \mathcal B_b \ne \varnothing \right\}$$
路径损耗为：
$$PL_{ij}(t) = PL_{FS}(d_{ij}(t),f_c) + L_{bld}(t) + X_{ij}(t)$$
默认：
- LoS：$L_{bld}=0$ dB；
- 建筑物遮挡：$L_{bld}=15$ dB；
- 敏感性：10、20、30 dB。

#### 6.3 空间相关阴影
$$\Delta s_{ij}(t) = \frac{ \vert{}\mathbf p_i(t)-\mathbf p_i(t-1)\vert{} + \vert{}\mathbf p_j(t)-\mathbf p_j(t-1)\vert{} }{2}$$
$$\rho_{ij}(t) = \exp \left( -\frac{\Delta s_{ij}(t)}{d_{corr}} \right)$$
$$X_{ij}(t) = \rho_{ij}(t)X_{ij}(t-1) + \sqrt{1-\rho_{ij}^2(t)} \sigma_s \epsilon_{ij}(t)$$
默认 $\sigma_s=4$ dB，$d_{corr}=50$ m。

#### 6.4 小尺度衰落
LoS 使用 Rician，NLoS 使用 Rayleigh：
$$\vert{}h_{ij,r}(t)\vert{}^2 = G_t G_r 10^{-PL_{ij}(t)/10} \vert{}g_{ij,r}(t)\vert{}^2$$
默认 LoS Rician $K=6$ dB，NLoS $K=0$。主训练使用槽级平均功率增益。

#### 6.5 不完美 CSI
$$\hat{h}_{ij,r}(t) = h_{ij,r} \left( t-a_{ij}^{CSI}(t) \right) \xi_{ij,r}(t)$$
$$10\log_{10}\xi_{ij,r}(t) \sim \mathcal N(0,\sigma_{CSI}^2)$$
actor 只能使用 $\hat h$、估计 SINR、上一槽有效速率、历史 outage 和 CSI AoI。真实 $h$ 仅用于环境转移和集中训练状态。

#### 6.6 第三 UAV 软遮挡
第三 UAV Fresnel 软遮挡不进入主训练环境。只有主实验完成后，才作为几何启发式消融或离线高保真验证扩展。

### 7. 固定资源组、SINR 与 outage

#### 7.1 固定资源组
总计 $R$ 个等效 RB 被划分为 $G=5$ 个连续、互不重叠的资源组：
$$\mathcal{G} = \left\{ \mathcal G_1, \ldots, \mathcal G_5 \right\}$$
每组包含 $R/G$ 个等效 RB。由于 $R\in\{10,20,40\}$，每组分别包含 2、4、8 个 RB。

发送 UAV 选择：
1. 一个起始资源组；
2. 一个资源宽度档位；
3. 一个功率档位。

资源组动作：
$$a_i^{rg}(t) \in \{\mathrm{idle},1,2,3,4,5\}$$
宽度档位：
$$a_i^{width}(t) \in \{1,2\}$$
宽度为 2 时使用起始组及其下一个相邻组；若起始组为 5，则宽度 2 必须被 mask。

功率档位：
$$p_i(t) \in \{0,0.25,0.5,1.0\}P_i^{\max}$$

#### 7.2 RB 指示变量
若链路 $i\rightarrow j$ 被联合执行器接受，且 RB $r$ 属于其所选资源组集合 $\mathcal S_i(t)$，则：
$$x_{ij,r}(t)=1$$
否则：
$$x_{ij,r}(t)=0$$
发射功率在已分配 RB 上平均分配：
$$p_{ij,r}(t) = \frac{p_i(t)} { \sum_{r=1}^{R}x_{ij,r}(t) }$$
仅在分母大于 0 时成立。

#### 7.3 SINR
$$\mathrm{SINR}_{ij,r}(t) = \frac{ x_{ij,r}(t) p_{ij,r}(t) \vert{}h_{ij,r}(t)\vert{}^2 }{ N_0B_{RU}F + \sum_{(k,l)\ne(i,j)} x_{kl,r}(t) p_{kl,r}(t) \vert{}h_{kj,r}(t)\vert{}^2 }$$

#### 7.4 有效速率
$$R_{ij}^{eff}(t) = \sum_{r=1}^{R} B_{RU} \log_2 \left( 1+\mathrm{SINR}_{ij,r}(t) \right) \mathbb 1 \left\{ \mathrm{SINR}_{ij,r}(t) \ge \gamma_{\min} \right\}$$
默认 $\gamma_{\min}=-3$ dB，并进行 $-6,0,3$ dB 敏感性分析。

#### 7.5 链路 outage 定义
仅对实际被调度且分配了非零资源的链路定义 outage：
$$O_{ij}(t) = \begin{cases} 1, & a_i^{tx}(t)=j,\ \vert{}\mathcal S_i(t)\vert{}>0,\ R_{ij}^{eff}(t)=0, \\ 0, & a_i^{tx}(t)=j,\ \vert{}\mathcal S_i(t)\vert{}>0,\ R_{ij}^{eff}(t)>0, \\ \mathrm{NA}, & \text{本槽未调度链路 } i\rightarrow j. \end{cases}$$
主动暂停、没有传输任务或没有分配资源时，不计为信道 outage。

历史 outage 只在实际被调度的历史时隙集合 $\mathcal H_{ij}(t)$ 上统计：
$$\hat{q}_{ij}^{out}(t) = \frac{ \sum_{\tau\in\mathcal H_{ij}(t)} O_{ij}(\tau) }{ \vert{}\mathcal H_{ij}(t)\vert{} }$$
当历史集合为空时，使用缺省值并附带可用性 mask。

可另外记录 RB 级失效率：
$$O_{ij}^{RB}(t) = \frac{ \sum_{r:x_{ij,r}(t)=1} \mathbb 1 \left\{ \mathrm{SINR}_{ij,r}(t) < \gamma_{\min} \right\} }{ \sum_r x_{ij,r}(t) }$$

### 8. 跨时隙通信与计算服务

#### 8.1 传输链路选择
每个 UAV 每个时隙最多选择一条槽初非空的传输队列：
$$a_i^{tx}(t) \in \{\mathrm{idle}\} \cup \left\{ j: Q_{i\rightarrow j}^{tx}(t)\ne\varnothing \right\}$$
该动作只服务已绑定任务，与新任务路由动作完全独立。

#### 8.2 链路聚合剩余 bit
定义链路队列总剩余数据量：
$$Q_{ij}^{bit}(t) = \sum_{n\in Q_{i\rightarrow j}^{tx}(t)} D_n^{rem}(t)$$
本时隙链路总服务预算为：
$$S_{ij}^{tx}(t) = \min \left\{ Q_{ij}^{bit}(t), R_{ij}^{eff}(t)\Delta t \right\}$$

#### 8.3 EDF 逐任务扣除
服务预算按照链路传输队列中的 EDF 顺序逐任务扣除：
1. 选择队首任务 $n_1$；
2. 扣除 $\min\{D_{n_1}^{rem},S_{ij}^{tx}\}$；
3. 若预算仍有剩余，继续服务下一个任务；
4. 直到预算耗尽或队列为空。

因此，一个时隙允许同一链路完成多个小任务，但不允许同时服务多个不同目的链路。
传输完成任务在槽末进入目的 UAV 的 CPU 队列，其全部计算量为 $C_n$。

#### 8.4 CPU 队列选择
每个 UAV $j$ 每个时隙最多选择一个槽初非空 CPU 队列：
$$a_j^{cpuq}(t) \in \{\mathrm{idle},\mathrm{local}\} \cup \left\{ i: Q_{i\rightarrow j}^{cpu}(t)\ne\varnothing \right\}$$
CPU 频率档位为：
$$f_j(t) \in \{0,0.25,0.5,1.0\} f_j^{\max}$$
设所选 CPU 队列的 EDF 队首任务为 $n^*$，则：
$$S_{j}^{cpu}(t) = \min \left\{ C_{n^*}^{rem}(t), f_j(t)\Delta t \right\}$$
第一版主实验每个 UAV 每槽最多计算一个任务，不继续服务第二个 CPU 任务。

#### 8.5 时隙事件顺序
每个时隙严格执行：
1. 读取槽初任务、队列、候选邻居、估计 CSI 和延迟消息；
2. 生成多头离散动作；
3. 对一个未绑定 EDF 任务执行路由决策；
4. 从槽初已有传输队列中选择一条链路；
5. 选择资源组、宽度和功率档位；
6. 选择一个 CPU 队列和 CPU 频率档位；
7. 运行联合 hard-feasible 执行器；
8. 根据真实信道计算 SINR、有效速率和通信服务；
9. 执行 CPU 服务；
10. 更新剩余 bit、cycle 和能量；
11. 结算 completed 与 expired；
12. 将本槽路由任务、传输完成任务和新到达任务在槽末入队；
13. 更新移动、真实信道、CSI AoI 和消息 AoI。

### 9. 能耗与联合硬约束

#### 9.1 通信能耗
$$
E_i^{tx}(t) = \Delta t \sum_{j,r} x_{ij,r}(t) p_{ij,r}(t)
$$

#### 9.2 CPU 动态能耗
$$
E_i^{cpu}(t) = \kappa_i \Delta t f_i^3(t)
$$
本文只统计主动通信/计算能耗，不将其称为完整 UAV 总能耗。

#### 9.3 剩余能量
$$
E_i^{act}(t) = E_i^{tx}(t) + E_i^{cpu}(t)
$$
$$
E_i^{act}(t) \le E_i^{res}(t)
$$
$$
E_i^{res}(t+1) = E_i^{res}(t) - E_i^{act}(t)
$$

#### 9.4 离散降档
若组合动作能量不可行，不映射为任意连续值，而按预定义离散档位降级：
$$
1.0 \rightarrow 0.5 \rightarrow 0.25 \rightarrow 0
$$
处理顺序为：
1. 先 mask 明显超过剩余能量的单分支档位；
2. 对联合动作重新计算能耗；
3. 若仍不可行，按固定优先规则降低功率或 CPU 档位；
4. 若所有非零组合均不可行，则对应分支执行 idle；
5. 记录降档次数、降档原因和执行前后动作。

#### 9.5 联合半双工约束
同一 UAV 在同一时隙不能同时发送和接收。由于多个 actor 同时决策，半双工不能只靠本地 mask 保证。
联合执行器按以下方式解析候选传输边：
1. 收集所有非 idle 候选传输边；
2. 按固定、可复现优先级排序；
3. 优先级可使用 EDF slack、估计链路质量和固定 UAV ID 作为最终 tie-break；
4. 依次接受不会导致任何 UAV 同时发送和接收的边；
5. 冲突边退化为通信 idle；
6. 记录半双工冲突与修正次数。

CPU 与通信允许并行，因为无线模块与 CPU 模块视为相互独立。

### 10. 观测、动作与信息权限

#### 10.1 actor 局部观测
**自身特征**
- 剩余能量比例；
- 归一化 $f_i^{\max}$、$P_i^{\max}$ 和 $\kappa_i$；
- 历史任务到达率估计 $\hat\lambda_i(t)$；
- 本地、传输和 CPU 队列统计；
- 各候选传输队列的任务数、总剩余 bit 和队首 slack；
- 各 CPU 队列的任务数、总剩余 cycle 和队首 slack；
- 上一槽动作与资源利用率。

**邻居节点特征**
- 相对位置和相对速度；
- 邻居广播的剩余能量比例；
- 邻居广播的最大 CPU、最大功率和能效特征；
- 邻居 CPU 负载与任务队列摘要；
- 消息 AoI。

**边特征**
- 估计距离；
- 估计 SINR；
- 上一槽有效速率；
- 仅基于已调度历史的 outage 率；
- CSI AoI；
- 相对速度；
- 特征可用性 mask。

actor 不直接读取真实建筑物遮挡标签、真实信道、未来位置、真实 $\lambda_i$ 或其他 UAV 的完整私有队列。

#### 10.2 critic 状态
集中训练期 critic 可使用：
- 所有 UAV 的真实资源参数；
- 所有任务和队列真值；
- 真实信道和遮挡状态；
- 真实业务到达参数；
- 建筑物和全局统计。

critic 必须使用集合式、图式或 padding-mask 结构，不能依赖固定 UAV 数量直接拼接。

#### 10.3 主动作空间
每个 UAV 的动作定义为：
$$
\mathbf{a}_i = \left( a_i^{route}, a_i^{tx}, a_i^{rg}, a_i^{width}, a_i^{pow}, a_i^{cpuq}, a_i^{cpuf} \right)
$$

| 动作分支      | 含义                                                  | 类型         |
| :------------ | :---------------------------------------------------- | :----------- |
| $a_i^{route}$ | 对一个槽初未绑定 EDF 任务选择 local、defer 或候选邻居 | 可变候选离散 |
| $a_i^{tx}$    | 选择一条槽初非空的已绑定传输队列                      | 可变候选离散 |
| $a_i^{rg}$    | 选择 idle 或固定资源组起点                            | 固定离散     |
| $a_i^{width}$ | 选择 1 或 2 个相邻资源组                              | 固定离散     |
| $a_i^{pow}$   | 选择功率档位                                          | 固定离散     |
| $a_i^{cpuq}$  | 选择本地或远程 CPU 队列                               | 可变候选离散 |
| $a_i^{cpuf}$  | 选择 CPU 频率档位                                     | 固定离散     |

#### 10.4 动作 mask
- 无未绑定任务时，route 固定为 idle；
- 不存在的邻居不可选；
- 已锁定任务不得重新路由；
- 无传输队列时，tx、resource group、width 和 power 固定为 idle；
- 资源组 5 不允许 width=2；
- 无 CPU 队列时，cpuq 和 cpuf 固定为 idle；
- 能量不足档位提前 mask；
- 被 mask 的 logit 设为足够小的有限值或使用框架支持的 masked categorical；
- 联合半双工冲突由环境执行器处理，而不是错误地假设单个 actor 可提前知道联合动作。

#### 10.5 路由与传输的独立语义
`route` 只负责新任务绑定，`tx` 只负责已有传输队列服务。即使二者在同一时隙同时输出，本槽新路由任务也不能被本槽 `tx` 动作服务。

### 11. 算法设计

#### 11.1 主方法：CA-GAT-MAPPO
**正式名称：** Constraint-Aware Graph MAPPO for Dynamic Heterogeneous U2U-MEC

**网络结构：**
- 局部节点、队列摘要和边特征；
- 一层边感知 GATv2；
- GRU；
- 七个多头 categorical 动作分支；
- 动作 mask；
- 联合 hard-feasible 执行器；
- 集合式集中 critic。

联合 log-prob 为有效动作分支 log-prob 之和：
$$
\log \pi_i(a_i|o_i) = \sum_{b\in\mathcal B_i(t)} \log \pi_i^{(b)} \left( a_i^{(b)} | o_i \right)
$$
被强制 idle 的无效分支不得错误进入 PPO 概率比。

#### 11.2 保底方法：分支式 GAT-QMIX
保底方法不再表述为完全未经修改的标准 QMIX，而定义为：**Factorized-Action GAT-QMIX**。

每个动作分支拥有独立 Q 头：
$$
Q_i(o_i, a_i) = \sum_{b\in\mathcal B_i(t)} Q_i^{(b)} \left( o_i, a_i^{(b)} \right)
$$
聚合后的局部 $Q_i$ 输入 QMIX 单调 mixer：
$$
Q_{tot} = f_{\mathrm{mix}} \left( Q_1,\ldots,Q_N,s \right)
$$

CA-GAT-MAPPO 与分支式 GAT-QMIX 共享：
环境转移、观测权限、七个动作分支、动作 mask、联合半双工解析器、离散降档、任务队列、奖励和评价指标。两者的差别仅在策略价值表示和训练更新方式。

#### 11.3 非学习基线
- **Local-Only-EDF：** 所有任务本地执行；
- **Greedy-Load-Aware：** 根据预计通信完成时间、邻居 CPU 余量和能量状态选择目的 UAV；
- **Random-Feasible：** 仅在 mask 后可行动作中随机；
- **Small-N MPC/枚举近优：** 仅用于 $N\le4$、短 horizon 的诊断场景。

不再增加大量重复的 IQL、VDN、QMIX 和多个 MAPPO 变体。

#### 11.4 算法公平性
比较算法必须使用相同：
任务到达和移动随机种子、建筑物布局和信道随机数、actor 信息权限、环境约束、训练步数和调参预算、测试场景集合。

### 12. 奖励函数与优化目标

#### 12.1 任务完成指标
每个时隙记录：
- $N_{on}(t)$：按 deadline 完成任务数；
- $N_{exp}(t)$：过期任务数；
- $W(t)$：紧迫工作量；
- $E^{act}(t)$：主动通信/计算能耗。

紧迫工作量定义为：
$$
W(t) = \sum_{n\in active} \frac{ D_n^{rem}/R_{\mathrm{ref}} + C_n^{rem}/f_{\mathrm{ref}} }{ \max \left( 1, t_n^{ddl}-t \right) }
$$

#### 12.2 团队奖励
$$
r(t) = w_c\widetilde N_{on}(t) - w_d\widetilde N_{exp}(t) - w_q\widetilde W(t) - w_e\widetilde E^{act}(t)
$$
初始权重仅作为调试起点：
$$
w_c=1.0, \qquad w_d=1.0, \qquad w_q=0.2, \qquad w_e=0.05
$$
所有归一化尺度使用固定参考值，不使用当前 batch 均值动态归一化。

#### 12.3 评价目标
论文主要报告：
按时完成率、过期率、平均/P50/P95 端到端时延、每个按时完成任务的主动能耗、队列积压、outage、约束修正率。折扣回报只用于训练，不直接等同于长期平均系统最优。

### 13. 实验设计

#### 13.1 实验族 A：基础环境机制与主性能
**固定：** $N=6$；$R=20$；Homogeneous 资源；CSI AoI = 0；参考业务负载分布。
**改变：** 建筑物遮挡：None、Low、Medium、High；全局任务负载：Low、Medium、High。
**目的：**
- 验证遮挡和负载的单调机制；
- 比较 Local-Only、Greedy、Random、分支式 GAT-QMIX 和 CA-GAT-MAPPO；
- 证明跨时隙队列和截止期机制有效。

#### 13.2 实验族 B：异构性专项实验
**固定：** $N=6$；$R=20$；Medium 建筑物；中等全局负载；CSI AoI = 0 或主场景固定值。
**分别改变：**

| 实验     | 控制方式                                            |
| :------- | :-------------------------------------------------- |
| 同构对照 | 所有 UAV 使用 Balanced profile，且 $\lambda_i$ 相同 |
| CPU 异构 | 仅改变 $f_i^{\max}$ 和配套 $\kappa_i$               |
| 通信异构 | 仅改变 $P_i^{\max}$                                 |
| 能量异构 | 仅改变 $E_i^0$ 和 $\kappa_i$                        |
| 负载异构 | 仅改变 $\lambda_i$，保持平均到达率不变              |
| 联合异构 | profile 与负载差异同时存在                          |

主文优先展示 Homogeneous、Mild-Heterogeneous 和 Strong-Heterogeneous 三档。单因素完整矩阵可放附录。

#### 13.3 实验族 C：鲁棒性与规模
固定主场景，分别改变：
$$
N\in\{4,6,8\}
$$
$$
R\in\{10,20,40\}
$$
$$
a^{CSI}\in\{0,3,5\}
$$
另外测试未见建筑物布局和未见 profile 组合。

以下内容不作为主论文必须条件：
- $N=10,12$ OOD；
- 第三 UAV 软遮挡；
- 连续资源动作；
- Sionna RT 回放。

#### 13.4 协同收益分析
Local-Only 和 Cooperative 策略必须在相同的：移动轨迹、建筑物布局、任务到达序列、信道随机数、资源 profile 分配、测试 episode 集合上进行配对比较。

不能只报告一个加权奖励，至少报告：按时完成率差值、P95 时延差值、能耗差值、过期率差值。

#### 13.5 统计规范
开发实验至少 5 个随机种子；最终主结果建议 10 个随机种子；报告均值、标准差、中位数和 95% 置信区间；主要指标使用配对差值和 bootstrap 或 permutation 检验；不以最好一次运行作为主要结论；同一算法使用公平的训练和调参预算。

### 16. 开发顺序与时间安排

- **阶段 0：参数与接口冻结**

  冻结七分支动作语义；冻结固定资源组；冻结任务状态机和槽边界；冻结资源 profile；完成链路预算与能量 pilot；冻结 $E_i^0$、$f_i^{\max}$、$\kappa_i$ 和 $R_{\mathrm{ref}}$。

- **阶段 1：环境和 Gate 0**

  实现任务、队列和状态转换；实现 route 与 tx_select 分离；实现固定资源组；实现通信/计算能耗；实现离散降档和半双工解析器；完成守恒、因果和信息权限测试。

- **阶段 2：物理机制和规则基线**

  实现移动、建筑物和拓扑；实现信道、SINR、CSI 和 outage；实现 Local、Greedy 和 Random；完成机制单调性测试。

- **阶段 3：保底学习方法**

  实现分支式 GAT-QMIX；验证多离散分支、mask 和 mixer；固定环境版本。

- **阶段 4：主方法**

  实现 GATv2+GRU actor；实现集合式 critic；实现多头 categorical MAPPO；验证 log-prob、置换等变和无未来信息。

- **阶段 5：论文实验**

  完成实验族 A、B、C；完成多种子统计；视时间增加扩展实验。

### 17. 验收闸门

| **闸门**                   | **通过标准**                                                 |
| -------------------------- | ------------------------------------------------------------ |
| **Gate P：参数可用**       | 链路预算、deadline 和能量 pilot 处于非退化区间               |
| **Gate 0：环境正确**       | 任务、bit、cycle、energy 守恒；route/tx 分离；槽因果正确；零非法状态转换 |
| **Gate 1：机制正确**       | 遮挡、干扰、CSI AoI、负载与资源异构产生预期单调趋势          |
| **Gate 2：规则基线可运行** | Local、Greedy、Random 稳定，无 NaN                           |
| **Gate 3：保底方法可学习** | 分支式 GAT-QMIX 稳定优于 Random-Feasible                     |
| **Gate 4：主方法成立**     | CA-GAT-MAPPO 在至少两个主实验族中优于匹配基线，且包含一个异构场景 |
| **Gate 5：结果可信**       | 多种子、配对测试、失败案例、复杂度和工程指标完整             |
| **Gate 6：扩展验证**       | 可选软遮挡或高保真轨迹与轻量模型趋势基本一致                 |

任何 Gate 未通过时，优先修复环境、动作接口或参数标定，不增加网络深度和额外预测头。

### 18. 论文创新点与表述边界

#### 18.1 可主张的贡献

- 构建面向动态异构 U2U-MEC 的任务级通信—计算—截止期联合环境；
- 显式区分 UAV 资源异构与业务负载异构；
- 设计新任务路由、已有传输队列服务、固定资源组和 CPU 队列服务相分离的多头离散决策接口；
- 通过现实局部观测、动作 mask、离散降档和联合半双工解析保证分散执行可行性；
- 分析资源异构、负载不均衡、遮挡和无线资源共同决定的协同收益条件；
- 在离线高保真传播轨迹上验证性能排序与退化趋势。

#### 18.2 不应主张的内容

- 不声称首次研究异构 UAV；
- 不声称首次提出 GATv2、GRU、MAPPO 或 QMIX；
- 不把分支式 GAT-QMIX 称为未经修改的标准 QMIX；
- 不把经验相图称为理论最优边界；
- 不把第三 UAV Fresnel 软遮挡称为实测模型；
- 不把轻量信道与高保真轨迹的趋势一致性称为真实信道证明；
- 不在缺乏公平调参和统计检验时声称全面优于所有算法。

### 19. 可选扩展

- **扩展 A：连续资源动作**

  只有离散主模型完成后，才考虑连续带宽、功率和 CPU 动作。连续动作必须重新设计概率分布、log-prob 和可行映射，不能与固定资源组二值变量混用。

- **扩展 B：第三 UAV 软遮挡**

  使用 Fresnel 清空率或几何启发式附加损耗，只作为敏感性和扩展验证。

- **扩展 C：Sionna RT 离线回放**

  保存时间对齐的 UAV 位置、建筑物场景、真实路径损耗或信道、CSI 估计、outage 标签，任务/移动/信道随机种子。仅验证趋势一致性和性能退化，不主张完全真实性证明。

- **扩展 D：离散硬件类型与类型 embedding**

  主模型只使用连续资源特征。只有存在无法由连续参数表达的固定硬件类别时，才引入类型标签和类型 embedding，并与无类型 embedding 的主模型进行消融。

- **扩展 E：UAV 数量 OOD**

  只有集合式 critic、padding、mask 和训练稳定性均通过后，才测试 $N=10,12$。

### 20. 最终冻结路线总结

1. 资源异构与负载异构分离；
2. profile 相关采样与能量标定；
3. 任务级 EDF 队列与明确槽边界；
4. 新任务路由与已有传输队列服务分离；
5. 固定五资源组与多头离散动作；
6. 建筑物遮挡、相关阴影、Rician/Rayleigh 和不完美 CSI；
7. 调度链路 outage 定义；
8. 离散降档与联合半双工解析；
9. CA-GAT-MAPPO 主方法；
10. 分支式 GAT-QMIX 保底方法；
11. 三个主实验族；
12. 多种子统计和协同收益分析；
13. 可选软遮挡、高保真回放、连续动作和数量 OOD。

**最终冻结核心原则：**

- `route` 只处理未绑定任务，`tx_select` 只处理已有传输队列；
- 主模型不选择任意 RB 起始位置，而选择固定资源组，全部使用离散动作；
- actor 使用历史到达率估计，不读取真实 $\lambda_i$；硬件异构由 profile 加小扰动生成；
- 初始能量和参考参数必须经过 pilot 校准；
- outage 只在实际调度链路上统计；半双工由联合执行器保证；
- GAT-QMIX 为分支式多离散变体；
- 若修改任务状态机、动作空间、资源 profile 或信息权限，必须同步更新系统模型、方法、实验协议和测试。
