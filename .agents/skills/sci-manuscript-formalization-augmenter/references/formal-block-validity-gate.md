# Formal Block Validity Gate

Before adding a formal block, answer:

1. What manuscript ambiguity does it remove?
2. What method, code, data, citation, or derivation supports it?
3. Are all variables defined?
4. Does the surrounding text use the block?
5. Does it change the claim strength?
6. Can it compile in the target LaTeX template?
7. What would make it false or misleading?

## Theorem-level extra gate

Theorems require:

- explicit assumptions
- precise statement
- proof or proof sketch
- no dependence on unverified empirical behavior
- clear distinction from heuristic or observation

If these are missing, downgrade to observation, design rationale, proposition candidate, or discussion text.
