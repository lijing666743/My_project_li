# Corpus Extraction Boundary

## Source Set

The phrase and formalization references in this update were informed by 11 user-supplied IEEE-series UAV/AAV/ISAC/MEC/RL PDFs from 2024-2025.

## Allowed Use

- Abstract rhetorical patterns.
- Section-function structures.
- Short phrase categories.
- Claim-strength discipline.
- Common formalization slots.

## Forbidden Use

- Do not copy long sentences or paragraphs from the papers.
- Do not reproduce paper-specific claims, numbers, baselines, or equations.
- Do not treat extracted phrase patterns as evidence for Kevin's manuscript.
- Do not cite these PDFs unless the user explicitly asks for a literature/citation task and the source is verified.

## Practical Rule

Use the corpus to learn how top IEEE manuscripts organize language, not to import their wording.
